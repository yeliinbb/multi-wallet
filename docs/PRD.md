## 1. 프로젝트 개요

- **프로젝트명:** Multi Wallet
- **서비스 정의:** 다중 언어 및 통화 지원 그룹 지출 기록 · 여행 가계부 앱
- **한 줄 설명:** 공동 지출, 다중 통화, 자동 환율, AI 기반 정산까지 — 여행자의 모든 지갑을 하나로 통합한 지출 관리 앱
- **목표:**
  - 일상과 여행 시 모두 사용 가능한 가계부 앱 제공
  - 공동 가계부 기능을 통해 여러 사용자와 함께 기록 및 관리
  - 소셜 기능을 통해 주변 사람들과 지출 내역 공유 및 비교 가능
  - 사용자의 소비 패턴을 분석하여 맞춤형 추천 및 예산 관리 지원

## 2. 기획 배경 및 문제 정의

### 2.1 개인적인 여행 경험에서 시작된 불편함

Multi Wallet은 실제 여행 중 겪은 불편한 상황에서 출발한 아이디어다. 특히 외국인 친구들과 함께 여행하거나, 해외에서 장기간 체류하며 다양한 통화로 지출한 경험 속에서 다음과 같은 문제들이 반복적으로 발생했다.

#### 문제 1: 외국인 친구들과의 공동 지출 정산 불편

- 한국의 간편 송금 서비스(카카오페이, 토스 등)는 외국인들이 사용할 수 없어 모든 결제를 내가 먼저 하고, 이후 현금으로 정산해야 했던 번거로운 상황이 자주 발생
- 송금과 정산 방식이 불편하고 아날로그적이며, 실수나 오해가 생기기 쉬운 구조

#### 문제 2: 여러 명이 함께 떠난 여행의 지출 내역 정리가 어려움

- 누가 어디서 얼마나 지출했는지 일일이 메모하거나 엑셀로 정리해야 했음
- 여행이 끝난 후 각자 얼마를 지불하고 정산해야 하는지를 투명하고 자동적으로 확인할 수 있는 툴이 부재

#### 문제 3: 장기 여행 시 여러 국가의 통화를 사용하는 상황에서의 계산 번거로움

- 유럽이나 동남아 등 여러 국가를 여행하며 다양한 통화로 결제하게 되는데, 이를 다시 기준 통화(예: 원화)로 일일이 환산해보며 총 지출액을 파악하는 과정이 매우 불편
- 환율은 수시로 변동되므로 정산 타이밍에 따라 실제 가치와 차이가 나는 문제도 존재

### 2.2 기존 가계부 앱이 해결하지 못한 틈새

- **일상 가계부 앱의 한계**
  - 대부분의 기존 가계부 앱(브로콜리, 뱅크샐러드 등)은 일상 속 개인 소비에 최적화
  - 은행 연동, 카드 내역 자동 불러오기 등 기능은 이미 토스, 네이버페이 같은 대형 플랫폼에서 제공
  - 여행 중의 복잡하고 다국적인 지출에는 대응하지 못함
- **공동 지출 관리에 약함**
  - 다수의 사람들과 함께 발생하는 공동 지출을 실시간으로 기록하고 자동으로 분배해주는 기능이 대부분의 앱에서 부실하거나 부재
  - 특히 언어나 통화가 다른 사용자를 함께 고려하는 구조는 거의 존재하지 않음

## 3. 기존 서비스와의 차별점

### 3.1 일상 + 여행 통합 가계부

| 구분 | 기존 여행 가계부 | Multi Wallet |
|------|-----------------|--------------|
| 사용 시기 | 여행 때만 사용 → 일상에서 잊혀짐 | 일상 + 여행 모두 사용 |
| 설치 | 여행 시 별도 다운로드 필요 | 하나의 앱으로 통합 |
| 소비 패턴 | 여행 시 소비만 분석 | 일상 + 여행 소비 패턴 종합 분석 |

### 3.2 공동 가계부 기능

- 기존 서비스에는 다른 사용자와 공동으로 관리할 수 있는 기능이 부재
- Multi Wallet은 링크 공유(QR/URL)를 통한 실시간 공동 작성 지원

### 3.3 지도 기반 소비 아카이브 (2차 기획 확장)

| 요소 | 기존 지도 앱 | Multi Wallet |
|------|-------------|--------------|
| 장소 기록 | 북마크처럼 저장 | 소비 정보 + 감정 + 경험 같이 기록 |
| 시각화 | 평면/핀 아이콘 중심 | 건축적 다이어그램 스타일로 루트 구조 표현 |
| 공유 방식 | URL or 스크린샷 | 감각적 루트 + 요약 카드 + 소비 분석 |
| 커뮤니티 | 거의 없음 | 팔로우, 루트 추천, 경험 공유 중심 |

## 4. 타겟 사용자 및 페르소나

### 4.1 타겟 정의

- 외국인 친구 또는 지인과 함께 여행하며 공동 지출 관리와 송금이 어려운 사람
- 친구, 연인, 가족과의 공동 지출을 쉽게 정리하고자 하는 사용자
- 여행이나 해외 출장이 잦아 다양한 국가의 화폐 사용으로 지출 내역 관리가 복잡한 사람
- 여러 나라를 여행하면서 현지 통화를 일일이 원화로 계산하여 지출을 관리하는 것이 불편한 사람
- 여행 후 지출 내역을 명확하게 정리하고 분석하여 다음 여행의 예산을 효율적으로 관리하고 싶은 사람

### 4.2 페르소나 ① — 김여행 (29세, 여성, 마케팅 매니저)

- **특성:**
  - 자주 해외여행을 다니며 현지에서 외국인 친구들과 동행하는 경우가 많음
  - 한국 간편 송금 서비스를 사용할 수 없는 외국인 친구들로 인해 지출 정산 시 번거로움을 자주 경험
  - 각국의 화폐로 지출한 내역을 일일이 원화로 환산하여 정리하는 것에 어려움
  - 여행 후 친구들과의 지출 내역 공유와 정산을 메신저나 엑셀로 관리하기 번거로움
- **니즈:**
  - 해외에서 간편하게 다양한 화폐로 친구들과 공동 지출을 기록 및 관리
  - 페이팔 등 글로벌 결제 API를 통한 간편 송금 및 정산
  - 실시간 환율 적용을 통해 여러 통화로 이루어진 지출을 자동으로 원화로 환산
  - 여행 후 상세한 지출 내역 리뷰 및 분석 기능
- **불편사항:**
  - 현금으로 정산하는 과정에서 발생하는 환전 비용과 분실 위험
  - 기존 앱들은 공동 지출 관리 및 해외 사용자 간 편리한 송금 지원이 부족

### 4.3 페르소나 ② — 박일상 (34세, 남성, IT 프리랜서)

- **특성:**
  - 해외 출장이 잦고, 다양한 국가에서 다양한 통화로 지출을 자주 함
  - 출장 지출 내역을 회사에 보고할 때 각국의 통화를 원화로 다시 환산하여 제출하는 과정이 번거로움
  - 출장과 개인 여행의 지출 관리를 별도로 명확하게 분류하고 싶음
- **니즈:**
  - 여러 통화를 실시간 환율로 자동 환산하여 지출을 편리하게 기록 및 관리
  - 출장 지출과 개인 지출을 명확히 분리하여 관리
  - 출장 후 지출 보고서를 간단히 생성하고 공유할 수 있는 기능
  - 지출 데이터를 시각적으로 쉽게 확인하고 분석
- **불편사항:**
  - 영수증을 일일이 보며 원화로 재계산하는 시간 소모
  - 출장 후 지출 보고 및 정산 과정이 비효율적

## 5. 기능 요구사항

### 5.1 MVP 기능

#### F1. 일상 및 여행 지출 기록

- **입력 필드:** 금액(입력), 지출 방식(선택), 그룹(선택), 카테고리(선택), 텍스트 & 사진 메모, 위치 정보
- **작성 방식:**
  - 단순 입력 (수동)
  - OCR 영수증 인식을 통한 자동 기록
  - AI Agent와 대화형 지출 기록
  - 기존 지출 내역 저장 후 shortcut으로 불러오기

#### F2. 카테고리 기반 지출 분류

- 기본 카테고리: 식비, 쇼핑, 관광, 교통, 숙박 등
- 사용자 커스텀 카테고리 추가 가능
- **AI 자동 카테고리 분류:** 위치 정보(Google Maps), 가게 이름, 사용자 과거 소비 패턴을 분석하여 자동 설정
  > 예시: "김여행 님이 스페인 바르셀로나의 한 식당에서 지출한 금액을 입력 → AI가 위치 정보 및 업종 정보를 분석하여 '식비'로 자동 설정"

#### F3. 다중 통화 및 언어 지원

- 한국어/영어 기본 지원 및 추가 다국어 확장 가능
- 사용자가 각종 통화로 지출 기록 가능

#### F4. 실시간 환율 적용

- 환율 API를 통해 지출 입력 시점의 실시간 환율로 자동 환산
- 다양한 통화로 기록된 지출을 하나의 기준 통화(예: 원화)로 변환
- 국가별 화폐 사용 내역은 따로 저장, 통합 총 지출은 기준 통화로 자동 계산

#### F5. 공동 가계부

- **초대 및 공유:** QR코드, URL 생성으로 링크 공유
- **실시간 공동 작성:** 사용자별 지출 입력 필드 포함
- **대시보드:** 참여 중인 사용자, 최근 활동 내역, 지출 요약 제공
- **자동 정산:** 개인별 총 지출액, 차액, 정산해야 할 금액 자동 계산

#### F6. 데이터 시각화 및 소비 패턴 분석

- 막대 그래프, 파이 차트 등으로 카테고리별/날짜별 지출 내역 시각화
- Three.js를 활용한 3D 시각화
- **시각화 데이터:**
  - 지역(국가, 도시)별 지출 비중
  - 지출 방식(현금, 신용카드, 모바일 결제 등) 비율
  - 일별/시간대별 지출 트렌드
  - 공동 지출 현황 (그룹 사용자별 지출 비율)

#### F7. 지도 연동을 통한 지출 트래킹

- 해외: Google Maps API
- 국내: Kakao API
- 소비 위치 및 이벤트 기록
- 특정 음식점에서의 소비 기록을 지도에 저장

#### F8. 달력을 통한 일/주간/월별 지출 조회

- 지출 정렬 이동 가능 (초기 정렬 순서는 생성일자 기준)
- 각 지출 항목에 사진 첨부 가능
- 달력을 통해 이벤트 기록 및 조회

#### F9. OCR 기반 영수증 스캔

- 영수증, 송장 등 이미지에서 자동으로 텍스트 인식
- 날짜, 금액, 상호 등 주요 정보를 추출하여 자동 입력
- 사용자가 별도로 입력할 필요 없이 자동 기록

#### F10. AI 에이전트

- 소비 데이터 및 기록을 분석하여 실시간으로 소비 패턴 인사이트 제공
- 개인 맞춤형 예산 조정, 지출 분류 추천
- 대화형 인터페이스를 통해 질문 시 실시간 소비 분석 결과와 개선 방안 안내
- OCR 결과의 자동 분류 및 검증 기능으로 데이터 입력 정확도 향상

#### F11. 알림 기능

- 지출 작성에 대한 주기적인 알림
- 공동 가계부 작성 관련 알림
- 특정 카테고리에서 과도한 지출 발생 시 사용자 알림

#### F12. 인증/인가

- 소셜 로그인: 카카오, 구글
- (가능 시) 인스타그램 연동 — 여행 지출 내역/장소를 SNS에 공유하여 유저 유입 촉진

### 5.3 여행 동선 시각화 상세 (2차 기획 핵심)

> **"단순히 소비를 기록하는 도구가 아니라, 시간·장소·감정이 연결된 경험을 기록하고 회고하고 공유할 수 있는 도구"**

#### 핵심 가치

1. **기억의 흐름을 시각적으로 복원** — 동선 + 소비 + 감정이 연결되는 구조
2. **공간 맥락에서 소비 패턴 이해** — 시간 중심이 아닌 공간 기반 분석
3. **경험 아카이브 / 나만의 여행 지도** — 공유형 여행 지도, 동선 기반 추천

#### 기능 상세

| 기능 | 설명 | 사용자 이점 |
|------|------|------------|
| 동선 시각화 | 지도에서 시간 순으로 지출 위치 연결 | 여행을 감정/기억 기반으로 되돌아봄 |
| 지출 밀도/테마 분석 | 위치별 소비 집중도 시각화 (heatmap or category icon) | 어느 공간에 더 많은 시간/돈/의미를 썼는지 인식 |
| 지출 루트 공유 | 나의 루트를 공유하거나 저장 | 친구나 다른 사용자에게 영감 |
| 루트 기반 리플레이 | 여행 하루를 타임라인으로 재생 (지출+사진) | 경험 기반 회고 |
| 소비 패턴 리포트 | "여행 시 걷는 루트당 평균 소비는?" 등 인사이트 | 공간 기반 소비 습관 파악 |

#### 3D 시각화 아이디어

1. **여행 루트 → 3D 경로 조각:** 시간 순서에 따라 높낮이가 다른 곡선, 지출 금액이 클수록 곡선이 높아짐 (Three.js Bezier curve)
2. **Memory Tower:** 각 장소에서의 지출을 작은 건축적 구조물로 표현 (카페=둥근 구조, 쇼핑=네모, 관광=뾰족)
3. **감정 그래프 3D 지형:** 동선 데이터 기반 감정의 높낮이를 가진 3D 땅 생성

## 8. UX/UI 설계 방향

### 8.1 디자인 원칙

- **직관적이고 깔끔한 스타일:** 다양한 통화를 다루는 경우, 통화 변환이 쉽게 가능하도록 인터페이스 설계
- **여행 모드와 일상 모드 간 원활한 전환:**
  - 디폴트: 기본적으로 국내 소비로 설정
  - 필요 시 사용자가 해외 소비로 전환할 수 있도록 옵션 제공
  - 국내/해외 필드 선택 추가 (라디오 버튼)
- **소비 패턴을 쉽게 파악할 수 있도록 시각적 분석 도구 제공**

### 8.2 디자인 고민 사항 (1차 기획 기준)

| 영역 | 고민 포인트 | 방향 |
|------|------------|------|
| 통화 확인 버튼 | 왼쪽 상단에 단독 유지 vs 별도 페이지 | 어디서든 빠르게 통화 확인 가능해야 함 |
| 메인 홈 | 카테고리별 지출 카드 UI만으로 충분한가? | 대시보드 느낌으로 다른 정보도 포함 |
| 소비 분석 | 지출/수입 외 추가 카테고리? | 추가 분류 카테고리 탐색 필요 |
| 지출 작성 | 단순 작성 vs AI 에이전트 작성 분리? | 뎁스를 높이는 것이 UX에 도움이 되는지 검토 |
| 마이페이지 | 프로필 수정 + 환경설정 외 추가 항목? | 그룹 관리, 저장한 지출 리스트 관리 검토 |

### 8.3 온보딩 UX (여행 동선 시각화 관련)

1. **빈 지도 + 부드러운 애니메이션 가이드**
   - "이곳이 당신의 여정을 담는 지도입니다"
   - "첫 장소를 기록해보세요"
   - 서서히 퍼지는 원형 노드 애니메이션
2. **샘플 다이어그램 오버레이**
   - 랜덤 예시 루트가 흐릿하게 지나감
   - "이런 식으로 여정이 기록됩니다"
3. **루트 기록 유도 CTA**
   - 지도 상단에 "+ 새로운 장소 기록하기" 버튼
   - 하단에 "루트가 연결되면, 이런 다이어그램이 그려져요" 미리보기
4. **기억 오브제 미리보기 카드**
   - "당신의 첫 루트가 만들어지면 이런 아트워크가 생성됩니다"

| Q7 | 여행 끝난 뒤에도 사용 가능? | 일상 지출 기록 모드도 제공, 국내 소비도 동일하게 기록 가능 |
| Q8 | 가격은? | 출시 초기 무료 베타, 이후 일부 고급 기능에 대해 프리미엄 요금제 도입 예정 |
| Q9 | 누가 잘 활용할 수 있나요? | 외국인 친구와 여행하는 사람, 다국가 장기 여행자, 디지털 노마드, 워홀러, 유학생, 출장 잦은 직장인 |

## 12. 향후 확장 계획

1. **다국어 지원 확장** — 한국어/영어 이후 추가 언어 지원
2. **AI 추천 기능 강화** — 특정 카테고리에 맞는 장소/이벤트 추천 (예: 미술관을 주로 가는 사람에게 해당 지역 전시 추천)

4. **결제 API 연동** — PayPal, TossPayments 등을 통한 앱 내 송금 기능
5. **리뷰 시스템** — 장소 기반 리뷰 기능 추가로 커뮤니티 활성화
